# Security

## Reporting a problem

If you find a security problem in any repository under `WILSONSLAWNMAINTENANCE` (an exposed key, a page that shows
something it should not, a way into a private room), please **do not open a public issue**. Instead, use GitHub's private
vulnerability reporting on the repository (**Security** tab → **Report a vulnerability**), or tell Christopher
(`@drasticstatic`), who keeps these pages.

## What we will never ask for

Nobody from the business or the lab will ever ask for a password, a sign-in code, a recovery code, a bank login, a wallet's
seed phrase or a key. If someone does, in the business's name or the lab's, the answer is no; please report it the same way.

## What these repositories never hold

No payments, no customer details, no prices, no keys or wallets. Public rooms carry only pages an owner listed, after a
tripwire that reads every file (SOP-OPS-003).
